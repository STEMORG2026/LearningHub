# Architecture Exceptions

**Version:** 3.0.0
**Status:** Active
**Owner:** Architecture
**Applies To:** All packages and apps
**Related:** `CONSTITUTION.md`, `RULES.md`

## Purpose

Records deliberate exceptions to architectural rules. Per the constitution (§47),
a violated rule must never be silently violated — record the exception here so it
remains visible to future agents.

## Exceptions

None currently recorded.

## Record Template

| Field | Value |
|-------|-------|
| Rule violated | _which rule from `RULES.md` / `CONSTITUTION.md`_ |
| Reason | _why the exception is required_ |
| Affected files | _file:line references_ |
| Risk | _what could go wrong_ |
| Temporary or permanent | _temporary / permanent_ |
| Human approval | _who approved and when_ |
| Review date | _when the exception will be re-evaluated_ |
