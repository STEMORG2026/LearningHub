## 0. THE 10 THINGS YOU MUST KNOW

1. **LearningHub is a pnpm + Turborepo TypeScript monorepo.** 23 packages under `packages/*`, 1 app at `apps/shell`. Version `3.0.0`, **`"private": true`**, Node `>=22.13`, pnpm `11.18.0`.
2. **`main` is RED.** Typecheck fails, tests fail in 3 packages, and the STEMMA knowledge seam is broken on the shell path.
3. **All of it traces to two commits 23 minutes apart on 2026-09-20** — `518615f` (synced an *empty* corpus, deleted 8 narrative files, stubbed curriculum mappings) and `2d4b209` (disabled all CI workflows).
4. **Everything is ~1–2 commits old and git-reversible.** This is a shallow, treatable break, not an architectural failure.
5. **`legacy/` is READ-ONLY. Never modify it.** It is the Strangler Fig source zone (ADR-001, ADR-004).
6. **Cross-package communication MUST go through the EventBus** (`packages/core/src/event-bus.ts`). Direct internal calls between packages are an architecture violation.
7. **`pnpm verify-governance` is a 13-stage gate.** It is the single most important command. It currently cannot complete, because it includes `typecheck`.
8. **`pnpm lint:arch` must always report 0 layer violations.** It currently reports 645 dependencies, 0 violations — keep it that way.
9. **Docs are governed.** Every file under `docs/` needs a status header: `CANONICAL`, `SUPERSEDED`, `HISTORICAL`, or `ARCHIVED`. `lint:doc-governance` enforces this.
10. **CI is disabled.** `.github/workflows-disabled/` holds the 10 workflow files. There is **no automated signal**. You must run checks locally. Do not re-enable without human approval.

`[FACT]` **The Iron Law:** (1) `legacy/` is read-only. (2) `packages/*` must not contain commercial pricing/marketing/single-product assumptions. (3) All cross-system integration uses versioned adapters or EventBus messages.

## 4. THE BREAK — EXACTLY WHAT IS WRONG

### 4.1 The chain

`518615f` updated the **producer** and not the **consumer**:

| | Producer (sync script) | Consumer (shell adapter) |
|---|---|---|
| Version | `SUPPORTED_EXPORT_VERSION = '2.1.0'` @ `scripts/generate/sync-lhs-knowledge.mjs:24` | `SUPPORTED_EXPORT_VERSION = '0.2'` @ `apps/shell/src/lib/lhs-adapter.ts:22` |
| Corpus | vendored **0 entities** (was 224) | expects populated corpus |
| Types | emits without `generated_at` in empty case | `lhs-types.ts:43` requires `generated_at: string` non-optional |
| Validation | none | `lhs-adapter.ts:24` — `knowledge as LhsKnowledgeExport` (unsound cast) |

### 4.2 The three typecheck errors (REL-001)

```
learning-path.ts(11,3)  TS2305  no exported member 'getCurriculumMapping'
learning-path.ts(67,53) TS7006  parameter implicitly has 'any' type
lhs-adapter.ts(24,16)   TS2352  conversion may be a mistake — missing 'generated_at'
```

### 4.3 The three failing test packages (REL-002)

| Package | Symptom | Root cause |
|---|---|---|
| `core` | 1 test fails | A doc lacks a `**Version:**` header |
| `content-engine` | **1 of 3 test files won't collect** | `tests/engine-gate-batch8.test.ts:17` imports deleted `apps/shell/src/data/narratives-batch8` |
| `apps/shell` | 18 failures | downstream of 4.1 |

### 4.4 Deleted / stubbed by `518615f`

- `narratives-batch1..8.ts` — **all 8 deleted**, ~8,494 lines. **Recoverable:** `git show 518615f^:<path>`.
- `curriculum-mappings.ts` — **547 → 18 lines**, `CURRICULUMS = {}`. **Recoverable** the same way.

### 4.5 The latent defect (REL-004) — verified

`packages/core/src/event-bus.ts:72-78`:

```ts
private dispatchToLocal(type: string, payload: EventPayload): void {
  for (const entry of this.subscribers) {
    if (entry.regex.test(type)) {
      entry.handler(payload);   // ⛔ NO try/catch
    }
  }
}
```

**Empirically reproduced:** with two subscribers on `a:*`, when the first throws, the second is **never reached** — dispatch aborts. One bad subscriber can silence all later ones. The file is 98 lines; the fix is ~5 lines.

## 6. RULES OF ENGAGEMENT

### Hard prohibitions

- 🚫 **Never modify `legacy/`.** It is frozen (ADR-004).
- 🚫 **Never delete packages** without human approval — especially the 6 orphans.
- 🚫 **Never re-enable CI workflows** without human approval (open decision D3).
- 🚫 **Never `git reset --hard` / `git push --force`** on `main`.
- 🚫 **Never commit secrets.** Redact anything credential-shaped in output.
- 🚫 **Never bypass hooks** (`--no-verify`) or signing.
- 🚫 **Never "fix" the test by deleting the test.** If `content-engine` cannot load, restore the file or fix the import — don't remove the suite.

### Mandatory practices

- ✅ **Run `pnpm lint:arch` after any cross-package change.** It must stay at 0 violations.
- ✅ **Use the EventBus** for cross-package communication. Never import another package's internals.
- ✅ **TypeScript strict mode is on.** Compiler options include `strict`, `exactOptionalPropertyTypes`, `noUncheckedIndexedAccess`, `verbatimModuleSyntax`. Write code that satisfies them; don't weaken the config.
- ✅ **Add a doc status header** to any new file under `docs/`.
- ✅ **Preserve the strict downward layering.** New dependencies must point down, never up.
- ✅ **Update coverage ratchets in `vitest.config.ts`** only in the improving direction.
- ✅ **Write tests before touching the STEMMA seam** — it is unvalidated at runtime today.

### When you are unsure

Ask. This repository has a human owner who is the sole author of 181/200 commits. The audit's open decisions D1–D3 exist precisely because the correct answer is a human judgement call, not an inference.

## 8. GOTCHAS THAT WILL BITE YOU

2. **`content-engine` tests do not "fail" — they cannot load.** The error looks like an import error, not a test failure. Do not chase it as a logic bug; it's a deleted file.
3. **`apps/shell/src/lib/lhs-adapter.ts` typechecks *because* of the `as` cast**, not because it's correct. Fixing the cast will surface errors that were previously hidden. That is the point.
