# @learninghub/content-engine

**Version:** 1.0.0

Content production engine — blueprint pipeline, additive formats, verification.

## Public API

- `createPipeline(config)` — Create a content production pipeline
- `addFormat(format)` — Add an output format to the pipeline
- `verify(content)` — Verify content meets quality standards

## Dependencies

- `@learninghub/content-provider`
